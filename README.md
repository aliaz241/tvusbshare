# TV USB Share

اپ ساده‌ای که با دسترسی روت، کارت SD خارجی گوشی رو به‌صورت USB Mass Storage
به یه دستگاه هاست بیرونی (مثل تلویزیون قدیمی با پورت USB) معرفی می‌کنه.

## نحوه ساخت
1. پوشه رو در Android Studio باز کن (Open an existing project).
2. Gradle sync خودش انجام میشه.
3. Build → Build APK(s)، یا مستقیم روی گوشی روت‌شده Run بگیر.

## نحوه استفاده
1. اپ رو باز کن، دکمه «بررسی» رو بزن.
2. در خروجی ببین `configfs` یا `legacy android_usb` کدومش "موجود" نشون داده میشه،
   و در لیست پارتیشن‌ها (`/proc/partitions`) دنبال microSD خارجی بگرد
   (معمولاً چیزی شبیه mmcblk1 یا mmcblk1p1، نه mmcblk0 که اکثراً حافظه داخلیه).
3. مسیر کامل پارتیشن (مثلاً `/dev/block/mmcblk1p1`) رو داخل فیلد متنی وارد کن.
4. دکمه «فعال‌سازی» رو بزن، بعد سیم USB رو به تلویزیون وصل کن.
5. بعد از اتمام کار، دکمه «غیرفعال‌سازی» رو بزن تا گوشی به حالت MTP عادی برگرده
   و دوباره بتونی فایل‌ها رو عادی ببینی/ویرایش کنی.

## نکات مهم
- کارت SD باید با فرمت FAT32 یا exFAT فرمت شده باشه؛ تلویزیون‌های قدیمی معمولاً
  ext4/f2fs رو نمی‌شناسن.
- وقتی UMS فعاله، خود اندروید دیگه به اون پارتیشن دسترسی نداره (exclusive lock) —
  طبیعیه که فایل‌منیجر گوشی در این حالت SD رو نبینه.
- اگه سیم USB معمولی (نه OTG) بین گوشی و تلویزیونه و تلویزیون نقش host رو داره،
  این روش درسته. اگه تلویزیون قابلیت host نداشته باشه (پورت USB فقط برای شارژ/سرویسه)،
  هیچ روشی جواب نمی‌ده.
